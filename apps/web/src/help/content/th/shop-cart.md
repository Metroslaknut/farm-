## ขั้นตอน

1. เปิด "ร้านค้า" ค้นหาหรือเลือกหมวดสินค้า
2. เปิดสินค้า เลือก "จำนวน" แล้วกด "เพิ่มลงตะกร้า"
   ![ส่วนจำนวนและปุ่มเพิ่มลงตะกร้า](img:1)
3. กด "ตะกร้า" ด้านบน เพื่อตรวจสินค้า แก้จำนวน หรือ "นำออก"
   ![หน้าตะกร้าของคุณ](img:2)
4. ที่ "คุณต้องการรับสินค้าอย่างไร?" เลือก "ฉันไปรับสินค้าเองจากผู้ขาย" หรือ "จัดส่งถึงฉัน" แล้วกรอกที่อยู่
   ![ตัวเลือกวิธีรับสินค้า](img:3)
5. ตรวจ "สรุปรายการ" แล้วกด "สั่งซื้อ"
   ![ปุ่มสั่งซื้อ](img:4)
6. ชำระเงินและติดตามสถานะที่คำสั่งซื้อของคุณ

:::note ซื้อจากหลายร้าน
ระบบจะแยกคำสั่งซื้อตามผู้ขาย และต้องชำระเงินแยกแต่ละคำสั่งซื้อ
:::

:::note กดสั่งซื้อแล้วยังไม่ถูกเก็บเงิน
ระบบจะกันสินค้าไว้ให้จนกว่าจะหมดเวลาชำระเงิน
:::

:::trouble ขึ้นว่าไม่สามารถจัดส่งได้
ผู้ขายบางรายไม่จัดส่งไปบางจังหวัด หรือให้รับสินค้าเองเท่านั้น เลือกวิธีรับใหม่ หรือนำสินค้านั้นออก
:::
