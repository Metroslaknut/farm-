สัตว์แต่ละตัวมีหน้าข้อมูลของตัวเอง ใช้บันทึกน้ำหนัก สุขภาพ การผสมพันธุ์ และลงประกาศขาย ต้องมี [ฟาร์ม](help:create-farm) ก่อน

## ขั้นตอน

1. ในฟาร์ม เปิดเมนู "สัตว์เลี้ยง" แล้วกด "ขึ้นทะเบียนสัตว์"
   ![ปุ่มขึ้นทะเบียนสัตว์ในหน้ารายการสัตว์](img:1)
2. "รหัสสัตว์" เว้นว่างได้ ระบบจะสร้างให้ เช่น A-00001
   ![ช่องรหัสสัตว์](img:2)
3. เลือก "ชนิดสัตว์" ก่อน แล้วจึงเลือก "สายพันธุ์"
   ![ช่องชนิดสัตว์และสายพันธุ์](img:3)
4. เลือก "เพศ" และใส่ "น้ำหนัก (กก.)" ถ้าชั่งแล้ว (ไม่บังคับ)
   ![ช่องเพศและน้ำหนัก](img:4)
5. ใส่ "วันเกิด" ถ้าไม่ทราบ ใส่อายุโดยประมาณแล้วกด "ใช้อายุโดยประมาณ"
   ![ช่องวันเกิดและอายุโดยประมาณ](img:5)
6. ถ้าทราบพ่อแม่ เลือก "พ่อพันธุ์ (พ่อ)" และ "แม่พันธุ์ (แม่)" จากสัตว์ในฟาร์ม
   ![ส่วนพ่อแม่พันธุ์](img:6)
7. กด "ขึ้นทะเบียนสัตว์"
   ![ปุ่มขึ้นทะเบียนสัตว์](img:7)
8. ระบบเปิดหน้าข้อมูลสัตว์ตัวนั้น จากหน้านี้ไปที่ "การเจริญเติบโต" "สุขภาพ" "แผนผังสายพันธุ์" หรือ "ประกาศขาย" ได้
   ![หน้าข้อมูลสัตว์ที่เพิ่งขึ้นทะเบียน](img:8)

:::note รหัสสัตว์
รหัสต้องไม่ซ้ำกันในฟาร์มเดียวกัน และแก้รหัสภายหลังไม่ได้
:::

:::trouble ไม่เห็นปุ่ม "ขึ้นทะเบียนสัตว์"
บทบาทของคุณในฟาร์มนี้อาจดูได้อย่างเดียว ให้เจ้าของฟาร์มเปลี่ยนสิทธิ์ ดู [ผู้ดูแลฟาร์ม](help:farm-staff)
:::

:::trouble เลือกสายพันธุ์ไม่ได้
ต้องเลือกชนิดสัตว์ก่อน ถ้าไม่มีชนิดที่ต้องการ ให้เพิ่มใน "ประเภทสัตว์ที่เลี้ยง" ของฟาร์ม
:::
