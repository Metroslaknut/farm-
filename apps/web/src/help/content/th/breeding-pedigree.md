## บันทึกการผสมพันธุ์

1. ในเมนูฟาร์ม เปิด "บันทึกฟาร์ม" แล้วเลือก "การผสมพันธุ์"
2. กด "เพิ่มบันทึกการผสมพันธุ์"
3. เลือกแม่พันธุ์ แล้วเลือก "พ่อพันธุ์ในฟาร์มนี้" หรือ "ไม่ทราบ / พ่อพันธุ์จากภายนอก" (ใส่ชื่อหรือรหัสหลอดน้ำเชื้อได้)
4. ใส่ "วันที่ผสมพันธุ์" ระบบจะคำนวณ "กำหนดคลอด" ให้ แล้วกด "บันทึก"

## เมื่อรู้ผล

1. เปิดบันทึกการผสมพันธุ์นั้น แล้วกด "บันทึกผลการผสม"
2. เลือกสถานะ: ตั้งท้อง คลอดแล้ว หรือไม่สำเร็จ
3. เมื่อคลอด กด "เพิ่มลูก" ระบบตั้งสายพันธุ์ลูกตามพ่อแม่ให้ แก้ไขได้ทุกตัว
4. สัตว์ปีก ใช้ "เริ่มฟักไข่" และ "บันทึกการฟัก" แทนการคลอด

## แผนผังสายพันธุ์

- ในหน้าข้อมูลสัตว์ กด "แผนผังสายพันธุ์" เพื่อดูพ่อแม่ ปู่ย่าตายาย และลูก
- เมนู "สายพันธุ์และความสัมพันธ์" แสดงบันทึกการผสมพันธุ์และการเกิดของทั้งฟาร์ม

:::note แผนผังมาจากข้อมูลที่บันทึกจริง
ถ้าไม่ได้ระบุพ่อหรือแม่ตอน [ขึ้นทะเบียนสัตว์](help:add-animal) แผนผังจะแสดงว่าไม่ทราบ
:::

:::trouble ไม่เห็นปุ่มเพิ่มบันทึกการผสมพันธุ์
ต้องมีสิทธิ์บันทึกการผสมพันธุ์ในฟาร์มนี้ ดู [ผู้ดูแลฟาร์ม](help:farm-staff)
:::
