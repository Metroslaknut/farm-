ฟาร์มคือที่เก็บข้อมูลสัตว์ทั้งหมดของคุณ ถ้ายังสร้างฟาร์มไม่ได้ ให้ [ขอสิทธิ์เจ้าของฟาร์ม](help:request-farm-owner) ก่อน

## ขั้นตอน

1. เปิด "ฟาร์มของฉัน" ถ้ามีสิทธิ์แล้วแต่ยังไม่มีฟาร์ม ระบบจะพาไปหน้า "ตั้งค่าฟาร์มของคุณ" เอง
   ![หน้าตั้งค่าฟาร์มของคุณ ขั้นที่ 1 ข้อมูลฟาร์ม](img:1)
2. กรอก "ชื่อฟาร์ม" เช่น [ตัวอย่าง] ฟาร์มสุขใจ
   ![ช่องชื่อฟาร์มที่กรอกแล้ว](img:2)
3. ที่ "ประเภทสัตว์ที่เลี้ยง" ติ๊กสัตว์ทุกชนิดที่เลี้ยง เลือกได้หลายอย่าง
   ![รายการประเภทสัตว์ที่เลี้ยงพร้อมช่องติ๊ก](img:3)
4. กด "ถัดไป"
   ![ปุ่มถัดไป](img:4)
5. เลือกจังหวัด อำเภอ/เขต และตำบล/แขวง (ไม่บังคับ ข้ามได้)
   ![ช่องจังหวัด อำเภอ และตำบล](img:5)
6. คลิกบนแผนที่ตรงที่ตั้งฟาร์มเพื่อปักหมุด แล้วกด "ถัดไป"
   ![แผนที่สำหรับปักหมุดตำแหน่งฟาร์ม](img:6)
7. ใส่เบอร์โทร อีเมล หรือ LINE ID (ไม่บังคับ แต่ช่วยให้ผู้ซื้อติดต่อได้) แล้วกด "บันทึกและเริ่มใช้งาน"
   ![ช่องทางติดต่อและปุ่มบันทึกและเริ่มใช้งาน](img:7)
8. ระบบจะเปิดหน้า "ภาพรวม" ของฟาร์ม เริ่มเพิ่มสัตว์ได้เลย
   ![หน้าภาพรวมของฟาร์มใหม่](img:8)

:::note แก้ไขภายหลังได้
ชื่อ ประเภทสัตว์ ที่ตั้ง และช่องทางติดต่อ แก้ได้ที่ "ข้อมูลฟาร์ม" ในเมนูฟาร์ม
:::

:::trouble กด "บันทึกและเริ่มใช้งาน" แล้วขึ้นว่าไม่มีสิทธิ์
บัญชียังไม่ได้รับสิทธิ์เจ้าของฟาร์ม ดู [ขอสิทธิ์เจ้าของฟาร์ม](help:request-farm-owner)
:::
