ต้องเป็น [ผู้ขายที่ได้รับอนุมัติ](help:verify-identity-seller) และเป็นเจ้าของหรือผู้จัดการฟาร์ม

## ขั้นตอน

1. เปิด "ตลาดสัตว์" กด "ขาย" แล้วกด "ดูประกาศขาย" ของฟาร์ม หรือในเมนูฟาร์มเลือก "ประกาศขายสัตว์"
   ![ปุ่มดูประกาศขายของฟาร์มในหน้าขายสัตว์](img:1)
2. กด "ลงประกาศใหม่"
   ![ปุ่มลงประกาศใหม่](img:2)
3. ที่ "สัตว์ที่จะขาย" เลือกจากสัตว์ของคุณ ชนิด สายพันธุ์ เพศ และอายุ จะคัดลอกให้เอง
   ![ช่องเลือกสัตว์ที่จะขาย](img:3)
4. ใส่ "ราคาตั้งขาย (฿)" และ "ราคาต่ำสุดที่คุณยอมรับได้" ซึ่งผู้ซื้อไม่เห็น ติ๊ก "รับข้อเสนอราคา" ถ้ายอมให้ต่อรอง
   ![ช่องราคาและรับข้อเสนอราคา](img:4)
5. ใส่ลิงก์รูปภาพ แล้วกด "บันทึกเป็นฉบับร่าง"
   ![ส่วนรูปภาพและปุ่มบันทึกเป็นฉบับร่าง](img:5)
6. ในหน้าประกาศ กด "ส่งตรวจสอบ" ผู้ดูแลจะตรวจก่อนแสดงในตลาด
   ![ปุ่มส่งตรวจสอบในหน้าจัดการประกาศ](img:6)

## เมื่อมีผู้ซื้อสนใจ

- ข้อเสนอราคาและคำสั่งซื้ออยู่ที่ "รายการซื้อขาย" ในเมนูฟาร์ม ตอบรับ ปฏิเสธ หรือต่อรองราคาได้
- เงินจากการขายดูได้ที่ "รายได้และการถอนเงินของฉัน"

:::note ข้อมูลที่ผู้ซื้อเห็น
ผู้ซื้อเห็นข้อมูลสัตว์ที่คัดลอกมาและรูปภาพ บันทึกสุขภาพและการผสมพันธุ์ยังเป็นข้อมูลส่วนตัวของฟาร์ม
:::

:::trouble กดบันทึกไม่ได้ และมีข้อความว่าเฉพาะผู้ขายที่ได้รับอนุมัติ
กด "สมัครเป็นผู้ขาย" ในข้อความนั้น ดู [ยืนยันตัวตนและสมัครเป็นผู้ขาย](help:verify-identity-seller)
:::

:::trouble ผู้ดูแลไม่อนุมัติประกาศ
อ่านเหตุผลในหน้าประกาศ กด "แก้ไข" ตามนั้น แล้วกด "ส่งตรวจสอบ" อีกครั้ง
:::
