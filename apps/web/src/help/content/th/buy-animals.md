## ค้นหาและยื่นข้อเสนอ

1. เปิด "ตลาดสัตว์" พิมพ์ชนิดหรือสายพันธุ์ในช่องค้นหา และใช้ตัวกรองราคา ชนิดสัตว์ และจังหวัด
   ![ช่องค้นหาและตัวกรองของตลาดสัตว์](img:1)
2. กดประกาศที่สนใจเพื่อดูราคาและรายละเอียด กด "☆ บันทึก" เพื่อเก็บไว้ดูภายหลัง
   ![หน้าประกาศพร้อมราคาและปุ่มบันทึก](img:2)
3. ที่ "ยื่นข้อเสนอราคา" ใส่ราคาที่ต้องการ แล้วกด "ส่งข้อเสนอ" ถ้าเป็นราคาตายตัว กด "ขอซื้อ"
   ![ส่วนยื่นข้อเสนอราคา](img:3)
4. ระบบเปิดหน้าการต่อรอง รอผู้ขายตอบรับ ปฏิเสธ หรือต่อรองกลับ ดูข้อเสนอทั้งหมดได้ที่ "ข้อเสนอของฉัน"
   ![หน้าการต่อรองที่รอผู้ขายตอบกลับ](img:4)

## สั่งซื้อและรับสัตว์

5. เมื่อตกลงราคาแล้ว กด "ดำเนินการสั่งซื้อ" เลือกว่าจะไปรับเองหรือให้จัดส่ง แล้วกด "ยืนยันคำสั่งซื้อ"
6. ชำระเงินและติดตามสถานะที่ "คำสั่งซื้อของฉัน" เมื่อได้รับแล้วกด "ฉันได้รับสัตว์แล้ว"
7. เงินคืนและประวัติการชำระดูได้ที่ "กระเป๋าเงิน"

:::note ถามผู้ขายก่อนตัดสินใจ
กด "ส่งข้อความถึงผู้ขาย" ในหน้าประกาศ อย่าโอนเงินนอกระบบ FARM+
:::

:::trouble กด "ดำเนินการสั่งซื้อ" แล้วขึ้นว่าการจองสิ้นสุดแล้ว
ราคาที่ตกลงมีเวลาจองจำกัด กลับไปที่การต่อรองแล้วตกลงกับผู้ขายอีกครั้ง
:::
