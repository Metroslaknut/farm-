สมัครฟรี ใช้อีเมลของคุณเองเพียงอีเมลเดียว เมื่อสมัครเสร็จต้องยืนยันอีเมลก่อนจึงจะเข้าสู่ระบบได้

## ขั้นตอน

1. กด "สมัครสมาชิก" ที่มุมขวาบนของหน้า (บนมือถือ กดไอคอนรูปคนที่มุมขวาบนก่อน แล้วกด "สมัครสมาชิก")
   ![ปุ่มสมัครสมาชิกที่มุมขวาบน](img:1)
2. ที่ "สมัครด้วย" เลือก "อีเมล"
   ![แท็บอีเมลในหน้าสมัครสมาชิก](img:2)
3. กรอก "ชื่อที่แสดง" "อีเมล" และ "รหัสผ่าน" อย่างน้อย 10 ตัวอักษร แล้วกรอกรหัสเดิมอีกครั้งที่ "ยืนยันรหัสผ่าน"
   ![ช่องชื่อ อีเมล และรหัสผ่านที่กรอกแล้ว](img:3)
4. กด "สมัครสมาชิก"
   ![ปุ่มสมัครสมาชิกใต้แบบฟอร์ม](img:4)
5. จะเห็นหน้า "ตรวจสอบอีเมลของคุณ" ให้เปิดอีเมลจาก FARM+ แล้วกดลิงก์ยืนยัน
   ![หน้าตรวจสอบอีเมลของคุณ](img:5)
6. เมื่อเห็น "ยืนยันอีเมลเรียบร้อยแล้ว" กด "เข้าสู่ระบบ"
   ![หน้ายืนยันอีเมลเรียบร้อยแล้ว](img:6)

:::trouble ไม่ได้รับอีเมล

- ดูในโฟลเดอร์จดหมายขยะ (Spam) หรือโฆษณา
- ในหน้า "ตรวจสอบอีเมลของคุณ" กด "ส่งลิงก์ยืนยันอีกครั้ง"
- ถ้าปิดหน้านั้นไปแล้ว ให้ไปที่ [เข้าสู่ระบบ](/farms/sign-in) กรอกอีเมลและรหัสผ่าน แล้วกด "ส่งลิงก์ยืนยันอีกครั้ง"
  :::

:::trouble ลิงก์หมดอายุหรือใช้ไม่ได้
หน้าจะขึ้น "ลิงก์ยืนยันหมดอายุหรือไม่ถูกต้อง" ให้กรอกอีเมลของคุณ แล้วกด "ส่งลิงก์ยืนยันใหม่"
:::

:::trouble ขึ้นว่า "อีเมลนี้มีบัญชีอยู่แล้ว"
คุณเคยสมัครด้วยอีเมลนี้แล้ว ให้ไป [เข้าสู่ระบบ](help:sign-in) แทน ถ้าจำรหัสผ่านไม่ได้ ดู [ลืมรหัสผ่าน](help:forgot-password)
:::
