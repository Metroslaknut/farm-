If you see "Your account cannot create a farm yet", you need farm-owner access first. The platform team reviews your request, and once it is approved you can create a farm.

## Steps

1. Open "My farms". If you have no farm yet, you will see "No farms yet"
   ![My farms with no farms yet](img:1)
2. Press the link "Request farm-owner access"
   ![The Request farm-owner access link below the message](img:2)
3. Fill in "Farm or business name (optional)", e.g. [Example] Sukjai Farm
   ![The request page with the farm name filled in](img:3)
4. In "Anything the reviewers should know (optional)", write which animals you raise and about how many
   ![The note to the reviewers filled in](img:4)
5. If you have documents, such as a farm registration, add the document name and an https link in the document fields
   ![The document type and document link fields](img:5)
6. Press "Send request"
   ![The Send request button](img:6)
7. Wait for the review. You can come back to this page any time to see the status badge
   ![The status badge of the farm-owner request](img:7)
8. When the status is "Approved", press "Create a farm"
   ![The message that your account can create farms and the Create a farm button](img:8)
9. Fill in the "Set up your farm" pages step by step, then press "Save and start"
   ![The Set up your farm page](img:9)

:::note How to make a document link
You can make a link with Google Drive, the same way as for a seller application. See [Verify your identity and become a seller](help:verify-identity-seller)
:::

## What each status means

- **Pending**: your request was sent and is waiting for the team to start
- **Under review**: the team is looking at your request
- **Approved**: you can create a farm at [Create a farm](/farms/new)
- **Rejected**: not approved. Read the reason and send it again
- **Suspended**: you cannot send a new request. Contact the platform team

:::trouble Your request was "Rejected"
Read "Reason from the reviewer" below the status badge, fix your details, then press "Send the request again"
:::

:::trouble You only want to help on someone else's farm
You do not need farm-owner access. Ask the farm owner to send you an invitation instead
:::
