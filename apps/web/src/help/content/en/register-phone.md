Registering is free with your own mobile number. When you finish, we send a 6-digit verification code by SMS so you can verify the number before you start.

## Steps

1. Press "Register" at the top right of the page (on a phone, press the person icon at the top right first, then "Register")
   ![The Register button at the top right](img:1)
2. Under "Register with", choose "Phone number"
   ![The Phone number tab on the registration page](img:2)
3. Fill in "Display name" and your "Mobile number" as digits only, e.g. 0800000000
   ![Display name and mobile number filled in](img:3)
4. Enter a "Password" of at least 10 characters, then type it again in "Confirm password"
   ![Password and confirm password filled in](img:4)
5. Press "Register"
   ![The Register button below the form](img:5)
6. You will see "Verify your phone number". Open the SMS from FARM+ and type the code in "6-digit verification code"
   ![The Verify your phone number page with the 6-digit code field](img:6)
7. Press "Verify and sign in". You are signed in straight away
   ![The Verify and sign in button](img:7)

:::trouble The SMS code did not arrive

- Wait about a minute. SMS messages are sometimes slow
- Check that the number shown on the screen is correct
- Next to "Did not get the code?", press "Send a new code" and use only the latest code
  :::

:::trouble The code is wrong or has expired
Check that you typed all 6 digits with no spaces. If it still fails, press "Send a new code" and enter the new code
:::

:::trouble It says "This phone number already has an account"
You registered with this number before. [Sign in](help:sign-in) instead. If you forgot the password, see [Forgot your password](help:forgot-password)
:::
